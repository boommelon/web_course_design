# 上传测试文件说明

本目录放课程系统演示时可选用的测试上传文件。

- `import-users-sample.csv`：管理员“数据导入”页面使用。
- `template-sample.txt`：管理员“文件模板管理”页面使用。
- `teacher-resource-sample.txt`：教师“资料管理”页面使用。
- `proposal-sample.txt`：学生“文档提交-开题报告”使用。
- `midterm-sample.txt`：学生“文档提交-中期检查”使用。
- `final-paper-sample.txt`：学生“文档提交-毕业论文”使用。
- `source-code-sample.txt`：学生“文档提交-源代码”使用。
