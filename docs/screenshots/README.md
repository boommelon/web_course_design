# 报告截图清单

本目录存放课程报告 `docs/课程设计项目报告.md` 第七章所需的运行截图。

## 要求

- 应用运行在 `http://localhost:8080/graduation-design/`。
- 文件名严格按下表，**不要改名**（报告里按此文件名引用）。
- 窗口宽度 ≥ 1366，等页面主要内容（表格/卡片/表单）加载完成后再截**整页**，保存为 PNG。
- 每切换角色先退出再登录。
- 列表类页面若为空，先造一两条演示数据再截，确保能体现真实功能。
